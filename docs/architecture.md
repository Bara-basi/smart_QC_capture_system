# 架构说明

```text
飞书多维表格 --增量同步--> Python API + PostgreSQL <--H5(Vue，嵌入飞书)-- 用户
                                  |
                                  +-- 签名上传 / 服务端上传 --> 阿里云 OSS
```

- **订单同步**：以飞书记录 ID 保存外部关联和同步水位；重复同步必须幂等。
- **规则引擎**：产品类别映射到版本化拍照模板；生成任务后保存快照，规则更新不影响历史任务。
- **图片**：数据库仅保存对象键、元数据和关联关系，图像二进制仅存 OSS。对象键建议以合同号/产品/任务/拍照项/UUID 组成。
- **身份**：前端获取飞书网页应用身份信息，后端校验后将飞书用户 ID 映射为本地用户及角色。
