# 配置清单

配置值放在 `backend/.env`，不可提交到 Git。

## 飞书

1. 创建企业自建应用并启用网页应用，配置 H5 首页地址与可信域名。
2. 申请并发布所需权限：获取用户身份、读取多维表格记录；如需回写状态，再增加写入权限。
3. 填入 App ID、App Secret、多维表格 App Token 与订单表 Table ID。
4. 明确订单表字段名称/类型及产品明细的表示方式（关联表或 JSON/文本）；实现同步前需将其映射为 `orders` 和 `products`。
5. 拍照通常使用浏览器的 `input[type=file][capture]`，以保证在飞书内外均可用；飞书 H5 JSSDK 只按需用于免登和预览等容器功能。

## 阿里云 OSS

1. 创建私有 Bucket，开启版本控制、服务端加密、生命周期规则和跨区域备份（按保留要求）。
2. 创建最小权限 RAM 子账号或 STS 角色，只授予该 Bucket 前缀的读写权限。
3. 填写 endpoint、bucket、访问凭据和对象前缀。生产环境优先使用 RAM 角色/STS，不在 `.env` 长期保存主账号密钥。
4. 通过受控下载接口或短期签名 URL 浏览图片，不把 Bucket 公开。

## PostgreSQL

创建独立数据库与最小权限应用账号；设置备份、恢复演练、连接加密和时区（建议 UTC）。
